# Beginner Roadmap (Python)

60 easy problems, one per day, in order. Each topic builds on the previous one.
`py new.py` always sets up the next problem you haven't started yet.

**How to approach each problem**
1. Read it twice. Work through the examples by hand on paper.
2. Write the simplest solution that works, even if it is slow. Slow and correct beats nothing.
3. Stuck for 20-30 minutes? Ask for a hint (not the answer), or read the Editorial's first idea, then close it and write the code yourself.
4. After it's accepted, write in your own words what the trick was. That note is where the learning sticks.
